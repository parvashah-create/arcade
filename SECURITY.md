# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users or vault data at risk.

Report it privately through [GitHub's security advisory form](https://github.com/parvashah-create/arcade/security/advisories/new). Include the affected Monochrome Arcade version, impact, reproduction steps, and any suggested mitigation.

You should receive an acknowledgement within seven days. Confirmed issues will be fixed and released as soon as practical, with public details shared after users have an update path.

## Scope

Monochrome Arcade does not intentionally access note contents, files outside the vault, or remote services. Reports about unexpected file access, network traffic, persistent background activity, unsafe HTML, or release artifacts that do not match their source are especially important.
